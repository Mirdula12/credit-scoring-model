# Credit Scoring Model

## Project Overview

This project builds a Machine Learning model to predict the creditworthiness of loan applicants based on their financial information.

The model helps financial institutions make lending decisions by classifying applicants as good or bad credit risks.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

---

## Dataset

German Credit Dataset from Kaggle:
https://www.kaggle.com/datasets/kabure/german-credit-data-with-risk

## How to Run

### Clone Repository

```bash
git clone https://github.com/Mirdula12/credit-scoring-model.git
```

### Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### Run Jupyter Notebook

```bash
jupyter notebook
```

Open:

```bash
notebooks/credit_scoring_model.ipynb
```
