# Credit Scoring Model

## Project Description
This project predicts the creditworthiness of loan applicants using Machine Learning.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Project Structure
- data/ → dataset files
- notebooks/ → Jupyter notebooks
- src/ → python scripts
- models/ → trained models
- outputs/ → results and graphs

## Goal
Build a machine learning model to support lending decisions by predicting whether a customer is creditworthy.
